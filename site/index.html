协作工作台 · 说明

协作工作台是什么

把团队讨论与派活全过程记录在工程里（git 历史即通信史）。协作以「邮局模型」运转：每个人一个收件箱，Agent 代为写信、投信、查信。

  • 工作区：每人一块地盘 workspaces/<user>，内含收件箱 inbox、任务包 tasks、草稿区与日志；共识沉淀到 share/
  • 四种公文：邮件（同步情况）/ 协同单（派活）/ 回执（应答）/ 退回（不接）；回执与退回必须 --ref 挂住原单，应答链不断
  • 五态任务包：未开始 / 进行中 / 阻塞 / 待确认 / 已完成，挂在个人 tasks/<任务名>/task.yaml，收敛状态供看板对齐
  • CI 治理：每次 push 后由 board.yml 聚合全部信件与任务，自动重建台账/看板/本页，并做 lint 违规质检

这个 Dashboard 是什么

CI 自动重建的只读审计视图——把散在各收件箱与任务里的元数据汇成一页，给演示与审计用；原始讨论正文回仓库看。Push 后约 30~90 秒刷新（Actions 排队为大头）。

  • 全局概览：信件总量、协同单闭环率、活跃任务、受阻事项，外加五态分布与活跃度排行
  • 消息审计：全部公文的收发流水，可按公文类型筛选，行内可追 ref 应答链
  • 任务看板：全员任务按五态分列，阻塞项标明被什么卡住
